Getting started

OpenVenue is a local-first designer for event spaces. The editor keeps one venue.json in this browser until you choose to export it.

Install

You need Node.js 22 and pnpm 10.20.0.

corepack enable
corepack prepare pnpm@10.20.0 --activate
pnpm install
pnpm dev

Open http://localhost:5173. The landing page leads to the project list. New project asks for a name, a hall size, a ceiling height, and either an empty hall or a rectangular room.

A first hall

  1. Draw walls with two clicks. A wall shorter than 0.2 m is rejected.
  2. Use Room for a rectangle, then place a table with one click.
  3. Drag a catalogue model onto the plan. The file records that model, so the save stays valid.
  4. Switch to 3D. Orbit, Isometric, and Walk show the same hall. Escape leaves Walk.
  5. Choose Map when the venue has more than one floor. Find lists rooms and tables.

Conference hall

Conference hall on the project list opens a 24 by 18 metre room with a door, a stage, a podium, 200 chairs, and a viewing gallery on the floor above. The file is examples/conference-hall.venue.json.

Save and check

Save JSON downloads the venue. Open JSON checks the file and keeps the current venue if it is invalid. Export also writes an SVG or PNG plan, a one-page PDF, or a GLB. Checks and the capacity figure are planning aids, not a certification.

The schema is described on the schema page. Models are described on the asset page.
