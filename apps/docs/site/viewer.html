Visitor map

apps/viewer is a read-only, embeddable venue map. It loads a venue.json (and optional content files) without the editor shell.

Run locally

pnpm --filter @openvenue/viewer dev

The demo venue opens by default. You can also pass ?url=/examples/map-demo.venue.json or any same-origin .json venue URL.

Author map places

In the editor, select a zone and set:

  • category — Find panel group (stages, food-drink, … or a custom key)
  • icon / mapColor / blurb — map markers and popover
  • links — one per line as Label|https://…
  • interaction.contentRef — richer menu/booth JSON outside the venue file

Floors may include mapMarkers (entrance, arrow, stair, elevator, exit) for circulation cues. See Schema for field details.

Visitor controls

  • 2D / 3D / Walk — shared Find, Search, floor filter, and selection
  • F Find · / Search · Esc close / All floors
  • Deep links: ?view=2d|3d|walk&floor=<id>&place=<zone-id>&url=…

Embed

Host the viewer build and point ?url= at a public venue JSON (or a public venue API URL). Keep content references same-origin or served through the public content endpoint.
