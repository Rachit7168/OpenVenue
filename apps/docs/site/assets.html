Asset guide

The editor ships thirty generated models. Each one is Apache-2.0, with its size and attribution recorded in apps/web/src/assets/catalogue.data.ts. Do not add a model that you cannot redistribute.

A model in the venue file

An asset record needs an id, a name, a format (glb, image, or audio), and a uri. An object that points at an asset id must have that asset in document.assets. Dropping a catalogue chair writes both the object and the asset, as one undo step.

Size

A generated model stays at or under 500 triangles. A box is 12 triangles. Repeated chairs share one mesh in the hall.

Imported GLB files

An imported model is untrusted. The editor refuses it when any of these are true:

  • The file is larger than 32 MB.
  • It is not glTF 2.0.
  • It uses an extension outside the allow-list, or its JSON contains a script or a forbidden key.
  • A buffer or image URI is anything other than an embedded data URL.

Catalogue files are loaded from this app. An import must not make the browser fetch another address.
